## 🚀 Быстрая установка

⚡ **Рекомендуется:** Протестировано и оптимизировано для серверов иарифного плана VPS-V [MyHosti.pro](https://myhosti.pro/services/vds)

```bash
curl -fsSL https://raw.githubusercontent.com/rootcraft-tech/-X-Ray-VLESS-Reality-Installer/main/install-xray.sh | sudo bash
```

## 🌟 Что такое VLESS + REALITY?

- **VLESS** - Современный протокол для обхода интернет-цензуры
- **REALITY** - Маскирует трафик под обычные HTTPS соединения  
- **Использует сертификаты реальных сайтов** - Не обнаруживается DPI системами
- **Высокая производительность** - Оптимизирован для скорости и стабильности
- **Корпоративный уровень безопасности** - Встроенная защита от злоупотреблений

## 🚀 Процесс установки

Скрипт автоматически выполняет следующие шаги:

1. **Обновление системы** - Обновляет пакеты Ubuntu (неинтерактивный режим)
2. **Настройка файрвола** - Конфигурирует UFW правила безопасности
3. **Установка X-Ray** - Скачивает и устанавливает последнюю версию X-Ray
4. **Генерация ключей** - Создаёт уникальные UUID и REALITY ключи
5. **Конфигурация** - Настраивает сервер с усиленной безопасностью
6. **Настройка логов** - Конфигурирует логирование доступа/ошибок с ротацией
7. **Инструменты мониторинга** - Устанавливает скрипты проверки безопасности и мониторинга трафика
8. **Запуск сервиса** - Включает и запускает X-Ray сервис
9. **Клиентские конфигурации** - Генерирует готовые к использованию настройки клиента

## 🔧 Управление после установки

### Просмотр конфигурации
```bash
# Просмотр клиентских конфигураций (защищено - только root)
cat /root/xray_client_configs.txt

# Просмотр серверной конфигурации
cat /usr/local/etc/xray/config.json
```

### Управление сервисом
```bash
# Проверка статуса сервиса
systemctl status xray

# Перезапуск сервиса
systemctl restart xray

# Остановка сервиса
systemctl stop xray

# Просмотр логов в реальном времени
journalctl -u xray -f
```

### Мониторинг логов
```bash
# Просмотр логов доступа (подключения клиентов)
tail -f /var/log/xray/access.log

# Просмотр логов ошибок
tail -f /var/log/xray/error.log

# Проверка последних 50 записей логов
tail -50 /var/log/xray/access.log
```

### Мониторинг безопасности
```bash
# Запуск комплексной проверки безопасности
/usr/local/bin/xray_security_check.sh

# Мониторинг статистики трафика
/usr/local/bin/check_xray_traffic.sh

# Проверка активных подключений
ss -tnp | grep :443

# Проверка статуса порта
ss -tlnp | grep :443
```

### Управление файрволом
```bash
# Проверка статуса файрвола
ufw status numbered

# Просмотр детальных правил файрвола
ufw status verbose
```

## 🛡️ Функции безопасности

### Безопасность протокола
- **REALITY Протокол** - Необнаруживаемая маскировка трафика
- **Подмена сертификатов** - Использует реальные сертификаты Microsoft.com
- **XTLS Шифрование** - Усиленная безопасность транспортного уровня
- **Порт 443** - Стандартный HTTPS порт для максимальной совместимости

### Фильтрация трафика
- **Блокировка SMTP** - Порты 25, 465, 587 заблокированы (предотвращение спам-рассылок)
- **Блокировка BitTorrent** - P2P протоколы автоматически фильтруются
- **Защита приватных IP** - Предотвращение сканирования внутренних сетей
- **Блокировка рекламных доменов** - Фильтрация рекламных сетей

### Безопасность системы
- **Интеграция с файрволом** - Автоматическая настройка UFW (только порты 22, 443)
- **Безопасные права файлов** - Файлы конфигурации защищены (chmod 640)
- **Ротация логов** - Автоматическое управление логами (хранение 7 дней)
- **Логирование доступа** - Комплексное отслеживание подключений
- **Логирование ошибок** - Детальная отчётность об ошибках для диагностики

### Мониторинг и оповещения
- **Монитор трафика** - Встроенный скрипт для анализа подключений
- **Проверка безопасности** - Автоматический инструмент валидации безопасности
- **Отслеживание SMTP попыток** - Мониторинг заблокированных попыток спама
- **Статистика подключений** - Отслеживание клиентских подключений в реальном времени

## 🚨 Решение проблем

### Проблемы с сервисом
```bash
# Перезапуск X-Ray сервиса
sudo systemctl restart xray

# Проверка детальных логов
sudo journalctl -u xray -n 50

# Проверка привязки порта
sudo ss -tlnp | grep :443

# Проверка процесса X-Ray
ps aux | grep xray
```

### Проблемы с подключением
```bash
# Проверка IP сервера
curl -4 ifconfig.me

# Тест доступности порта с клиента
telnet YOUR_SERVER_IP 443

# Проверка правил файрвола
sudo ufw status verbose

# Проверка конфликтов портов
sudo netstat -tlnp | grep :443
```

### Проверка конфигурации
```bash
# Тест X-Ray конфигурации
/usr/local/bin/xray -test -config /usr/local/etc/xray/config.json

# Просмотр текущей конфигурации
cat /usr/local/etc/xray/config.json

# Проверка клиентских конфигураций
cat /root/xray_client_configs.txt
```

### Проверки безопасности
```bash
# Запуск аудита безопасности
/usr/local/bin/xray_security_check.sh

# Проверка SMTP попыток (должно быть 0)
grep -E ":(25|465|587)" /var/log/xray/access.log | wc -l

# Просмотр заблокированных подключений
grep "blocked" /var/log/xray/access.log

# Проверка прав файла конфигурации
ls -l /usr/local/etc/xray/config.json
```

### Анализ логов
```bash
# Просмотр последних записей доступа
tail -100 /var/log/xray/access.log

# Поиск ошибок
grep -i error /var/log/xray/error.log

# Мониторинг активности в реальном времени
tail -f /var/log/xray/access.log

# Проверка статистики трафика
/usr/local/bin/check_xray_traffic.sh
```

## 🔐 Лучшие практики безопасности

### Защита конфигурации
- ⚠️ **НИКОГДА не делитесь UUID публично** - Это пароль к вашему VPN
- ⚠️ **НИКОГДА не коммитьте `/root/xray_client_configs.txt` в публичные репозитории**
- ✅ Храните конфигурации в защищённом менеджере паролей
- ✅ Держите резервные копии в зашифрованном хранилище

### Усиление безопасности сервера
- ✅ Используйте сильные SSH ключи, отключите аутентификацию по паролю
- ✅ Включите автоматические обновления безопасности: `dpkg-reconfigure -plow unattended-upgrades`
- ✅ Измените SSH порт с дефолтного 22 (обновите UFW правила соответственно)
- ✅ Установите fail2ban для защиты SSH: `apt install fail2ban`

### Мониторинг
- ✅ Запускайте проверки безопасности еженедельно: `/usr/local/bin/xray_security_check.sh`
- ✅ Мониторьте логи на подозрительную активность
- ✅ Проверяйте счётчик SMTP попыток (всегда должен быть 0)
- ✅ Регулярно просматривайте паттерны целевых IP

### Обновления
- ✅ Держите X-Ray обновлённым до последней версии
- ✅ Регулярно обновляйте системные пакеты: `apt update && apt upgrade`
- ✅ Подпишитесь на уведомления о безопасности X-Ray
- ✅ Тестируйте обновления сначала на не-продакшн сервере
